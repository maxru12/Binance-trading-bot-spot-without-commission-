**Простой, эффективный и полностью автоматический бот для сеточной торговли парой DOGE/FDUSD на спотовом рынке Binance.**

> 💡 **Почему DOGE/FDUSD?**
> Пары со стейблкоином **FDUSD** позволяют торговать **без комиссии**, при условии использования лимитных ордеров (Maker). В этом боте данная логика реализована по умолчанию, что существенно увеличивает чистую прибыль.

---

## ✨ Основные возможности

Бот написан на **Node.js**, использует **WebSocket** для моментальной реакции на рынок и не требует сложной настройки.

### 🧠 Умная стратегия
*   **Сеточная торговля:** Поддержка равномерной или нелинейной сетки (по умолчанию до 20 уровней, можно расширить до 300).
*   **Накопление объема:** С каждым уровнем объем ордера растет, что снижает среднюю цену входа и приближает точку выхода в плюс .
*   **Адаптивность:** Автоматический расчет шага сетки на основе волатильности (анализ 5-минутных свечей).
*   **Режимы ордеров:** Размещение всей сетки (ордеров) сразу (`ALL_AT_ONCE`) или последовательно (`SEQUENTIAL`).

### 📊 Мониторинг и Прибыль
*   **Цель:** Один общий ордер на продажу по формуле: `Средняя цена закупки + % профита`.
*   **Отслеживание PnL:** Считает реализованную и нереализованную прибыль (День/Неделя/Месяц). Данные сохраняются в `JSON`.
*   **CLI Дашборд:** Красивый интерфейс в консоли, обновляющийся каждые 3 секунды (Цены, Баланс, Текущие ордера, Статистика).

### 🛡️ Безопасность и Надежность
*   **Mutex:** Защита от одновременных противоречивых операций.
*   **Авто-восстановление:** Переподключение WebSocket при обрывах связи.
*   **Защита от простоев:** Подтяжка сетки при резком росте цены .
*   **Валидация:** Проверка всех лимитов Binance (Min Notional, Price Filters).
*   **Логирование:** Ротация лог-файлов в папке `./logs`.

# 📦 Установка

## 1. Клонирование

```
git clone https://github.com/YOUR_USERNAME/binance-doge-grid-bot.git
cd binance-doge-grid-bot
```

## 2. Установка зависимостей

```
npm install
```

## 3. Создайте файл `.env`

```
BINANCE_API_KEY=your_key
BINANCE_API_SECRET=your_secret
```

## 4. Запуск

```
node bot.js
```

# 🛠 Настройки

Все параметры находятся в начале файла `bot.js`.

### Основные ключевые настройки:

Параметр,Описание,Значение по умолчанию
PROFIT_TARGET_PERCENT,Процент прибыли от средней цены,0.3
FIXED_NOTIONAL,Сумма первого ордера (FDUSD),1.3
MAX_GRID_POSITIONS,Макс. уровней сетки,20   (макс 50 и можно больше ,(бинанс позволяет до 300) 
GRID_MODE,'LINEAR' или 'NONLINEAR','NONLINEAR'
ORDER_PLACEMENT_MODE,'ALL_AT_ONCE' или 'SEQUENTIAL','SEQUENTIAL'
GRID_STEP_AUTO_ENABLED,Автошаг по волатильности,true
GRID_PULL_DELAY_MINUTES,Задержка подтяжки сетки (мин),2.5
